## 📖 About

This project is my personal portfolio website, built to showcase my background, technical skills, projects, and experiences in software development.

The portfolio is designed as more than just a collection of projects. It represents my journey as an **Informatics Engineering student**, developer, and creative who enjoys combining technology with design.

The website provides a central place to learn more about me, explore my projects, and connect with me professionally.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* [Node.js](https://nodejs.org/)
* npm
* Git

### Installation

Clone this repository:

```bash
git clone https://github.com/aidilprmdta/portofolio.git
```

Navigate into the project:

```bash
cd portofolio
```

Install dependencies:

```bash
npm install
```

### Environment Variables

If the project requires environment variables, create a `.env` file based on `.env.example`:

```bash
cp .env.example .env
```

Then configure the required variables.

### Run Development Server

```bash
npm run dev
```

The website will be available at:

```text
http://localhost:4321
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
